# 🌸 Perfume Website

A modern and responsive perfume e-commerce website built using **HTML, CSS, and JavaScript**.  
This project focuses on clean UI, smooth animations, and interactive user experience.

---

## ✨ Features

- 🛍️ Product gallery with image slider
- 🛒 Add to Cart functionality (LocalStorage based)
- 🌙 Dark Mode toggle
- 🔍 Search functionality
- 📱 Fully responsive design
- 📂 Accordion sections
- 🎯 Scroll fade-in animations
- 🔔 Toast notifications

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- LocalStorage
